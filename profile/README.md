## Featured work

### ROYAL — luxury fine-dining website

A cinematic, bilingual (English / Myanmar) website for a fictional fine-dining restaurant on the Hlaing riverfront in Yangon,
with a live table-booking demo and an interactive 3D floor plan.

**[▶ Open the live site](https://dev-by-humblekids.github.io/RoyalRestaurant/)** · [Source code](https://github.com/Dev-By-HumbleKids/RoyalRestaurant)
